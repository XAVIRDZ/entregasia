1. Introducción y Fundamentos Teóricos

El clasificador Naive Bayes es un método probabilístico supervisado basado en el Teorema de Bayes, que asume que todas las características predictoras son condicionalmente independientes entre sí dada la clase:

$$P(C_k \mid \mathbf{x}) = \frac{P(C_k) \cdot \prod_{i=1}^n P(x_i \mid C_k)}{P(\mathbf{x})}$$

Donde:

  • P(Ck): Probabilidad a priori de pertenecer a la especie Ck.
  • P(xi | Ck): Verosimilitud de la característica condicional a la clase.
  • Dado que las cuatro variables biométricas del conjunto Iris son continuas, el modelo ajusta una distribución Normal (Gaussiana) con parámetros μ (media) y σ (desviación estándar).

2. Preparación del Entorno y Carga de Datos

Utilizamos el paquete e1071, el cual implementa el algoritmo clásico de Naive Bayes en R:

# Si no está instalado: install.packages("e1071")
library(e1071)

# Cargar el dataset nativo de Iris
data(iris)

# Inspeccionar estructura general
str(iris)
head(iris)
table(iris$Species)

3. División en Datos de Entrenamiento y Prueba

Dividimos el conjunto de 150 instancias en un 80% de entrenamiento (120 flores) y un 20% de prueba (30 flores):

set.seed(123)
indices <- sample(1:nrow(iris), size = 0.8 * nrow(iris))
train_data <- iris[indices, ]
test_data  <- iris[-indices, ]

cat("Flores en entrenamiento:", nrow(train_data), "\n")
cat("Flores en prueba:", nrow(test_data), "\n")

4. Entrenamiento del Clasificador con naiveBayes

Ajustamos el modelo sobre las 4 variables predictoras:

# naiveBayes(fórmula, data)
modelo_nb <- naiveBayes(Species ~ ., data = train_data)

# Imprimir el modelo con las medias y desviaciones estimadas
print(modelo_nb)

5. Predicción y Evaluación de Desempeño

Evaluamos el modelo con el subconjunto de prueba test_data:

# Generar predicciones categóricas
predicciones <- predict(modelo_nb, test_data)

# Matriz de Confusión
matriz_conf <- table(Predicho = predicciones, Real = test_data$Species)
print(matriz_conf)

# Exactitud global (Accuracy)
exactitud <- sum(diag(matriz_conf)) / sum(matriz_conf)
cat("Exactitud alcanzada en el conjunto de prueba:", round(exactitud * 100, 2), "%\n")

6. Conclusiones

  1. Separabilidad de Iris-setosa: El modelo identifica a la especie setosa con un 100% de precisión debido a la brecha clara en las medidas del pétalo.
  2. Distribución Gaussiana: Entre versicolor y virginica existe un ligero solapamiento natural que el modelo estima probabilísticamente con alta precisión (>95%).
  3. Eficiencia en R: Mediante el paquete e1071, la implementación es compacta, rápida y adecuada para variables biométricas continuas.
